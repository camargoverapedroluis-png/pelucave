Función de transferencia de segundo orden

G(s) = (ωn²/a)·(s + a)/(s² + 2ζωn s + ωn²). Arrastre un deslizador: la curva se transforma y la anterior queda como fantasma.

Telaraña del mercado

P(k+1) = (a − c − d·P(k))/b con a = 10, b = 1, c = 1, d = 0.8: converge a P* = 5.
